MOVIE / BOOK LIBRARY
Made for: Vaibhavi Agrahari

FEATURES
- Add movie or book details
- Store title, type, genre and rating
- Search by title
- Filter by movie/book
- Filter by genre
- Pagination
- Delete an item
- Data is saved in the browser using localStorage

HOW TO RUN

1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The project will open in your browser.
5. You do NOT need MongoDB, Java, Maven or any server for this basic version.

FILES
- index.html  -> page structure
- style.css   -> design
- script.js   -> JavaScript functionality
- README.txt  -> instructions

NOTE
This version is intentionally basic and uses browser localStorage instead of a database.
